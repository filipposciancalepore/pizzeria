# Relazione di laboratorio – Realizzazione sito web Pizzeria

## 1. Obiettivo

L'obiettivo del laboratorio è stato quello di realizzare un sito web dedicato a una pizzeria, utilizzando i linguaggi HTML e CSS e imparando a utilizzare GitHub per condividere e organizzare il lavoro.

Il sito doveva essere composto da tre pagine web:

- **Menu Pizze:** contenente i nomi delle pizze, le immagini, le descrizioni e i prezzi.
- **Menu Bevande:** contenente l'elenco delle bevande disponibili e i relativi prezzi.
- **Menu Dolci:** contenente i dolci disponibili, le descrizioni e i prezzi.

Un altro obiettivo era imparare a collaborare in gruppo, dividendo il lavoro tra tre persone, ognuna responsabile della realizzazione di una pagina web.

## 2. Procedimento

Per prima cosa abbiamo organizzato il lavoro, dividendo i compiti tra i tre componenti del gruppo.

Ogni componente si è occupato della realizzazione di una pagina:

- **Primo componente:** ha realizzato la pagina del menu delle pizze, inserendo immagini, descrizioni e prezzi.
- **Secondo componente:** ha realizzato la pagina del menu delle bevande, inserendo le bevande disponibili e i relativi prezzi.
- **Terzo componente:** ha realizzato la pagina del menu dei dolci, inserendo i dolci disponibili, le descrizioni e i prezzi.

Per realizzare il sito abbiamo utilizzato:

- **HTML:** per creare la struttura e organizzare i contenuti delle pagine.
- **CSS:** per personalizzare la grafica, i colori, le dimensioni e la disposizione degli elementi.
- **GitHub:** per caricare, condividere e organizzare i file del progetto.

Successivamente abbiamo seguito questi passaggi:

1. Abbiamo creato un repository su GitHub.
2. Abbiamo realizzato le tre pagine web utilizzando HTML.
3. Abbiamo personalizzato le pagine con CSS.
4. Abbiamo caricato i file HTML, CSS e le immagini su GitHub.
5. Abbiamo collegato le tre pagine attraverso pulsanti e collegamenti, permettendo all'utente di passare facilmente da un menu all'altro.
6. Infine, abbiamo controllato il funzionamento del sito.

## 3. Conclusione

Al termine dell'attività siamo riusciti a realizzare un sito web per una pizzeria composto da tre pagine: menu pizze, menu bevande e menu dolci.

Durante il laboratorio abbiamo imparato a utilizzare HTML e CSS per creare e personalizzare pagine web e abbiamo approfondito l'utilizzo di GitHub per caricare e condividere i file di un progetto.

Il lavoro di gruppo ci ha permesso di dividere i compiti, collaborare e unire le diverse pagine in un unico progetto.

Questa esperienza è stata utile per mettere in pratica le conoscenze acquisite e comprendere meglio come si realizza e si organizza un progetto web.
